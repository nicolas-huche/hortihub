# Catalog

How to find and select a product?

## Catalog Structure

Category -> Product Family -> Product

### Examples

- Fruit -> Banana -> Prata Banana
- Fruit -> Banana -> Nanica Banana
- Vegetable -> Tomato -> Italian Tomato

## Alternative

Instead of navigating the catalog, a user can search for the desired Product.

## Business Rules

- A Product must be added to the Cart before an Order can be created.
