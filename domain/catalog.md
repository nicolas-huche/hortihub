# Catalog

How to find and select a product?

## Catalog Structure

**Category -> Product Family -> Product**

### Examples

- Fruit -> Banana -> Prata Banana
- Fruit -> Banana -> Nanica Banana
- Vegetable -> Tomato -> Italian Tomato
